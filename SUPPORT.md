# Support

## Questions and design discussions

Use [GitHub Discussions](https://github.com/realmroot/adapters/discussions) for
architecture questions, integration design, and community help once
Discussions are enabled.

## Bugs and feature requests

Use the repository's issue templates:

- bug reports for reproducible project defects;
- feature requests for changes to existing provider behavior;
- provider proposals for new external platforms.

This project is currently pre-release. There is no production support or
compatibility guarantee yet.

## Security

Do not use Discussions or public issues for vulnerabilities. Follow
[SECURITY.md](SECURITY.md).
